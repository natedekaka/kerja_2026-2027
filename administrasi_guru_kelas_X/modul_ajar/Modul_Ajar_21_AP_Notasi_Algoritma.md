### B. TUJUAN PEMBELAJARAN

#### B.1 Tujuan Pembelajaran
1. Menjelaskan pengertian dan fungsi notasi algoritma (pseudocode dan flowchart) dalam pengembangan program.
2. Menuliskan pseudocode dengan struktur dan aturan penulisan yang benar sesuai standar (case insensitive, indentation, kata kunci baku).
3. Menggambar flowchart menggunakan simbol-simbol standar (terminal, input/output, proses, decision, connector) secara tepat.
4. Mengonversi pseudocode ke flowchart dan sebaliknya secara akurat.
5. Menyelesaikan studi kasus sederhana dengan menyusun pseudocode dan flowchart secara lengkap.

#### B.2 Indikator Keberhasilan
| Indikator | Kriteria |
|---|---|
| 1. Menjelaskan notasi algoritma | Mampu mendefinisikan pseudocode dan flowchart serta menyebutkan minimal 3 perbedaan keduanya |
| 2. Menulis pseudocode | Pseudocode mengandung 5 kata kunci baku (INPUT, OUTPUT, IF, FOR, WHILE) dengan indentasi yang konsisten |
| 3. Menggambar flowchart | Flowchart memuat simbol terminal, proses, decision, dan input/output dengan alur logis yang benar |
| 4. Konversi pseudocode-flowchart | Tidak ada kesalahan logika pada hasil konversi |
| 5. Studi kasus | Pseudocode dan flowchart menyelesaikan masalah dengan tepat |

#### B.3 Kata Kunci
Pseudocode, flowchart, algoritma, notasi algoritma, terminal, decision, input/output, proses, statement, indentasi, logika pemrograman

#### D.4 Rubrik Penilaian Produk Pseudocode & Flowchart
| Aspek | SB (4) | B (3) | C (2) | PB (1) |
|---|---|---|---|---|
| **Ketepatan pseudocode** | Pseudocode sesuai logika masalah, indentasi rapi, menggunakan kata kunci baku secara konsisten | Pseudocode sesuai logika dengan 1-2 kesalahan minor dalam kata kunci atau indentasi | Pseudocode kurang sesuai logika, indentasi tidak konsisten, beberapa kata kunci tidak tepat | Pseudocode tidak sesuai logika, tanpa indentasi, tidak menggunakan kata kunci baku |
| **Ketepatan flowchart** | Semua simbol tepat, alur logis, tidak ada cabang yang menggantung, rapi | Sebagian besar simbol tepat, 1-2 simbol kurang tepat, alur logis | Beberapa simbol salah, alur kurang logis, terdapat cabang yang menggantung | Simbol tidak tepat, alur tidak logis, tidak selesai |
| **Konversi pseudocode-flowchart** | Keduanya konsisten sempurna — setiap blok pseudocode memiliki padanan flowchart | Konsisten dengan 1-2 perbedaan minor | Kurang konsisten — terdapat bagian pseudocode yang tidak ada di flowchart atau sebaliknya | Tidak konsisten — pseudocode dan flowchart berbeda secara signifikan |
| **Ketepatan waktu** | Selesai sebelum batas waktu dan siap dipresentasikan | Selesai tepat waktu | Selesai dengan tambahan waktu 5 menit | Tidak selesai |

#### E.1 Soal Konversi (Mudah)
Flowchart berikut menggambarkan algoritma menentukan bilangan genap/ganjil. Konversikan ke dalam pseudocode!

```
[Flowchart: Mulai → Input angka → angka % 2 == 0? → Ya: Output "Genap", Tidak: Output "Ganjil" → Selesai]
```

**Tulis pseudocode Anda di sini:**
```
START
INPUT angka
IF angka % 2 == 0 THEN
    OUTPUT "Genap"
ELSE
    OUTPUT "Ganjil"
ENDIF
END
```

#### E.2 Studi Kasus (Sedang)
Toko "Diskon Jaya" memberikan aturan diskon sebagai berikut:
- Jika total belanja > Rp200.000, diskon 20%
- Jika total belanja > Rp100.000, diskon 10%
- Selain itu, tidak mendapat diskon
- Pajak 5% diterapkan setelah diskon (jika total setelah diskon > 0)

Buatlah pseudocode dan flowchart untuk menghitung total yang harus dibayar!

**Struktur jawaban:**
1. Tulis pseudocode dengan indentasi yang rapi
2. Gambar flowchart menggunakan simbol-simbol standar
3. Uji dengan data: total belanja = Rp150.000

**Hasil pengujian manual:**
- Total belanja: Rp150.000 → diskon 10% = Rp15.000 → total setelah diskon = Rp135.000 → pajak 5% = Rp6.750 → total bayar = Rp141.750

#### E.3 Tantangan (Sulit)
Buatlah pseudocode dan flowchart untuk program "kalkulator akar persamaan kuadrat". Program menerima input nilai a, b, c dari persamaan ax² + bx + c = 0, kemudian:
- Menghitung diskriminan (D = b² - 4ac)
- Jika D > 0: menampilkan dua akar real berbeda
- Jika D == 0: menampilkan satu akar real kembar
- Jika D < 0: menampilkan "Akar imajiner"
