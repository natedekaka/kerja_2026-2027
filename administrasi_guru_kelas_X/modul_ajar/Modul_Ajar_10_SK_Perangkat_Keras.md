### B. TUJUAN PEMBELAJARAN

#### B.1 Tujuan
1. Mengidentifikasi komponen-komponen utama perangkat keras komputer (CPU, RAM, motherboard, storage, PSU, GPU) secara visual.
2. Menjelaskan fungsi masing-masing komponen dan bagaimana mereka saling terhubung.
3. Membedakan jenis-jenis storage (HDD, SSD, NVMe) dan pengaruhnya terhadap kinerja.
4. Merancang spesifikasi PC sesuai kebutuhan (gaming, desain, coding, office) dengan anggaran tertentu.
5. Menerapkan keselamatan kerja (K3) saat membongkar dan merakit komputer.

#### B.2 Indikator Keberhasilan
- [ ] Peserta didik menyebutkan minimal 6 komponen HW dan fungsinya dengan benar.
- [ ] Peserta didik menjelaskan alur data dari input hingga output dalam sistem komputer.
- [ ] Peserta didik membuat spesifikasi PC impian dengan anggaran Rp10 juta yang realistis.
- [ ] Peserta didik mengikuti prosedur keselamatan saat hands-on dengan komponen.

#### B.3 Kata Kunci
Hardware, CPU, processor, RAM, motherboard, HDD, SSD, NVMe, GPU, VGA, PSU, power supply, casing, input device, output device, storage, clock speed, core, cache, bus, form factor

#### D.3 Asesmen Sumatif
**Bentuk:** Proyek — Spesifikasi PC Impian
**Tugas:** Buat proposal spesifikasi PC/Laptop dengan anggaran Rp10 juta. Sertakan:
1. Tujuan penggunaan (gaming/desain/coding/umum)
2. 5 komponen utama (CPU, RAM, Storage, GPU, Motherboard) + spesifikasi detail
3. Harga masing-masing komponen (dari toko online nyata)
4. Total biaya
5. Alasan pemilihan setiap komponen

#### D.5 Contoh Soal/Tugas
**Soal:** Seorang siswa ingin membeli laptop untuk:
- Membuat presentasi dan dokumen (MS Office)
- Coding Python ringan
- Browsing dan streaming
- Budget maksimal Rp8.000.000

Spesifikasi minimum apa yang kamu rekomendasikan? Jelaskan alasanmu!

**Jawaban Referensi:**
- CPU: Intel i5 generasi 12+ / AMD Ryzen 5 (cukup untuk coding ringan)
- RAM: 8GB (minimal untuk multitasking Word + browser + IDE)
- Storage: 512GB SSD (lebih cepat dari HDD, cukup untuk file dan aplikasi)
- GPU: Integrated (tidak perlu dedicated untuk kebutuhan ini)
- Layar: 14-15,6 inch Full HD
- Baterai: minimal 6 jam

### H. BAHAN BACAAN UNTUK GURU

1. **Tips:** Pinjam PC bekas lab. Pastikan mati dan tidak teraliri listrik.

2. **Jika Tidak Ada PC:** Video YouTube, PC Building Simulator, pcpartpicker.com.

3. **Error Umum:** CPU disamakan casing, RAM = Storage, semua punya GPU, PSU = baterai.

4. **Analogi:** Motherboard = jalan raya, CPU = otak, RAM = meja kerja, Storage = lemari, PSU = jantung.

5. **Keamanan:** Cabut listrik, gelang anti-statis, pegang tepi PCB.
