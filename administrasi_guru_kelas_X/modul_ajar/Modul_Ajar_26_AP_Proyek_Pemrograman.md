### B. TUJUAN PEMBELAJARAN

#### B.1 Tujuan Pembelajaran
1. Merencanakan pengembangan program dengan menentukan fitur, membuat pseudocode, dan merancang struktur fungsi-fungsi yang dibutuhkan.
2. Mengimplementasikan program Python terstruktur (minimal 50 baris) yang menggabungkan konsep variabel, percabangan, perulangan, dan fungsi.
3. Melakukan pengujian program dengan minimal 3 skenario berbeda dan mendokumentasikan hasil pengujian.
4. Melakukan peer review terhadap program teman dan memberikan masukan yang konstruktif.
5. Mendemonstrasikan program yang telah dibuat dan merefleksikan proses pengembangan.

#### B.2 Indikator Keberhasilan
| Indikator | Kriteria |
|---|---|
| 1. Perencanaan | Menuliskan minimal 3 fitur program, membuat pseudocode, dan mengidentifikasi 2+ fungsi yang diperlukan |
| 2. Implementasi | Program berjalan tanpa error, menggunakan minimal 1 percabangan, 1 perulangan, dan 3 fungsi |
| 3. Pengujian | Menguji dengan 3 skenario (normal, batas, error) dan mencatat hasil dalam tabel |
| 4. Peer review | Memberikan 2+ masukan spesifik pada program teman |
| 5. Demonstrasi | Menjelaskan fitur dan alur program dengan percaya diri |

#### B.3 Kata Kunci
Proyek pemrograman, software development lifecycle, perencanaan, implementasi, pengujian, debugging, dokumentasi, peer review, program terstruktur, modular, fungsionalitas

#### E.2 Opsi Proyek
**Opsi A — Program Pengelolaan Daftar Tugas (Todo List)**
Fitur minimal:
- Menambahkan tugas baru (input: nama tugas, deadline)
- Melihat semua tugas (ditampilkan dalam format tabel)
- Menandai tugas selesai (ubah status dari "Belum" ke "Selesai")
- Menghapus tugas
- Menu interaktif (loop while)

Contoh struktur data: list of dictionary
```python
tugas = [
    {"nama": "Belajar Python", "deadline": "2026-06-10", "status": "Belum"},
    {"nama": "Kerjakan LKPD", "deadline": "2026-06-08", "status": "Selesai"}
]
```

**Opsi B — Program Kalkulator BMI + Kategori Kesehatan**
Fitur minimal:
- Input: nama, berat badan (kg), tinggi badan (cm)
- Hitung BMI = berat / (tinggi/100)^2
- Tampilkan kategori: Kurus (<18.5), Normal (18.5-24.9), Gemuk (25-29.9), Obesitas (>=30)
- Simpan riwayat dalam list
- Tampilkan riwayat semua perhitungan

**Opsi C — Program Data Nilai Siswa**
Fitur minimal:
- Input data 5 siswa (nama, nilai tugas, nilai UTS, nilai UAS)
- Hitung nilai akhir = (tugas*20% + UTS*35% + UAS*45%)
- Tentukan grade (A/B/C/D/E) dan status (Lulus/Tidak Lulus)
- Tampilkan laporan dalam format tabel
- Hitung rata-rata kelas, nilai tertinggi, nilai terendah

### F. DIFERENSIASI PEMBELAJARAN

| Level | Deskripsi |
|---|---|
| **Level 1 (Bimbingan)** | Siswa diberikan template kode yang sudah berisi struktur dasar (menu dan 1 fungsi contoh). Siswa cukup melengkapi 2 fungsi tambahan dengan panduan langkah demi langkah. Pendampingan intensif dari guru. |
| **Level 2 (Reguler)** | Siswa mengerjakan proyek dari awal dengan panduan LKPD. Siswa bekerja individu atau berpasangan. Minimal 3 fungsi dan 50 baris kode. |
| **Level 3 (Percepatan)** | Siswa mengerjakan proyek dengan spesifikasi yang lebih kompleks. Kode minimal 80 baris, minimal 5 fungsi, menyimpan data ke file eksternal (CSV/txt), dan memiliki fitur edit data. Siswa juga diminta menambahkan validasi input yang komprehensif. |
