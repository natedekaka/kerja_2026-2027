#### D.5 Contoh Soal/Tugas
**Soal:** Seorang sekretaris OSIS membuat laporan keuangan. Data pemasukan dan pengeluaran ada di Excel. Ia ingin membuat laporan narasi di Word dan presentasi di PowerPoint. Jelaskan langkah-langkah yang harus dilakukan agar ketika data Excel berubah, laporan Word dan presentasi PowerPoint ikut berubah secara otomatis!

**Jawaban:**
1. Buat tabel dan chart di Excel.
2. Di Word: gunakan Paste Special → Paste Link untuk tabel dan chart.
3. Di PowerPoint: gunakan Paste Special → Paste Link untuk chart.
4. Simpan semua file dalam folder yang sama.
5. Saat data Excel diubah, buka Word → akan muncul prompt "Update Links" → klik Yes. PowerPoint juga akan meminta update.
6. Alternatif: klik kanan objek → Update Link.

### H. BAHAN BACAAN UNTUK GURU

1. **Tips:** Simpan semua file di folder yang sama sebelum linking. Jika file dipindahkan, link putus.

2. **Error Umum:** Link putus, chart tidak muncul (versi Office), prompt update tidak muncul (security), data tidak update (salah pakai Paste biasa), file corrupt.

3. **Keamanan:** Word blokir auto link update. Aktifkan di File → Options → Advanced → Update automatic links at open.

4. **Office vs Google:** MS Office paste link stabil. Google Workspace integrasi seamless. LibreOffice open source.

5. **Studi Kasus:** Laporan bulanan: database → Excel → Word → PPT. Satu data berubah, semua update otomatis.
