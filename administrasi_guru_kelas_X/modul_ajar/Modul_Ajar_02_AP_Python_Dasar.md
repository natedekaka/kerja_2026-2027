| Tugas Praktik | Program profil diri dengan ketentuan: (1) Input: nama, umur, kelas, hobi, (2) Output kalimat lengkap, (3) Minimal 3 tipe data berbeda, (4) Tidak ada error |

#### D.4 Rubrik Penilaian Program Python

| Kriteria | SB (4) | B (3) | C (2) | PB (1) |
|---|---|---|---|---|---|
| **Variabel** | 4+ variabel dengan nama deskriptif | 3 variabel, nama sesuai konvensi | 2 variabel | <2 variabel |
| **Tipe Data** | Menggunakan 4 tipe data (int, float, str, bool) | 3 tipe data | 2 tipe data | 1 tipe data |
| **Input/Output** | Input & output format rapi, user-friendly | Input & output berfungsi | Hanya output | Tidak ada I/O |
| **Kebersihan Kode** | Kode rapi, komentar, tidak ada error | Rapi, tidak ada error | Ada error minor | Banyak error |

#### D.5 Contoh Program Target

```python
# Program Profil Diri
nama = input("Masukkan nama kamu: ")
umur = int(input("Masukkan umur kamu: "))
tinggi = float(input("Masukkan tinggi badan (cm): "))
kelas = input("Masukkan kelas: ")

print("\n========== PROFIL DIRI ==========")
print(f"Halo, namaku {nama}.")
print(f"Aku berumur {umur} tahun.")
print(f"Tinggiku {tinggi} cm.")
print(f"Aku duduk di kelas {kelas}.")
```

### H. BAHAN BACAAN UNTUK GURU

- **Python untuk Pemula:** Gunakan analogi "variabel = kotak penyimpanan", "tipe data = jenis barang yang disimpan"
- **Error Umum:** NameError (salah nama variabel), TypeError (operasi antar tipe berbeda), ValueError (input tidak sesuai)
- **Tools Alternatif:** Jika Python IDLE tidak tersedia, gunakan Replit.com (akses web, gratis) atau Google Colab
- **Strategi Debugging:** Ajarkan siswa membaca error message — ini keterampilan paling penting dalam coding!
