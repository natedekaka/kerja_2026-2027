### B. TUJUAN PEMBELAJARAN

#### B.1 Tujuan Pembelajaran

1. Membedakan jenis jaringan berdasarkan luas area: LAN, MAN, WAN, dan internet.
2. Mengidentifikasi fungsi perangkat jaringan: router, switch, modem, access point, repeater.
3. Menjelaskan kelebihan dan kekurangan 4 topologi jaringan: star, bus, ring, mesh.
4. Memeragakan bentuk topologi jaringan melalui simulasi fisik dengan tali rapia.
5. Mengidentifikasi perangkat jaringan nyata di lingkungan sekolah.

#### B.2 Indikator Keberhasilan

| Indikator | Kriteria |
|---|---|
| Mampu membedakan LAN, MAN, WAN dengan contoh masing-masing | Minimal 2 ciri pembeda per jenis jaringan |
| Mampu menyebutkan 5 perangkat jaringan & fungsinya | 4 dari 5 perangkat dijelaskan dengan benar |
| Mampu membentuk 4 topologi jaringan dalam simulasi | 3 dari 4 topologi terbentuk dengan benar |
| Mampu menggambar topologi jaringan sekolah/rumah | Terdapat simbol perangkat dan jalur koneksi |

#### B.3 Kata Kunci

LAN, MAN, WAN, internet, router, switch, modem, access point, repeater, topologi star, topologi bus, topologi ring, topologi mesh, node, bandwidth, protokol

### H. BAHAN BACAAN UNTUK GURU

1. **Model OSI vs TCP/IP:** Jaringan komputer bekerja berdasarkan model referensi OSI (7 layer) dan TCP/IP (4 layer). Untuk tingkat SMA, cukup diperkenalkan TCP/IP: Network Interface, Internet, Transport, Application. Protokol seperti HTTP, FTP, DNS berada di layer Aplikasi; TCP/UDP di Transport; IP di Internet; Ethernet/WiFi di Network Interface.
2. **Collision Domain vs Broadcast Domain:** Dalam topologi bus, semua perangkat berada dalam satu collision domain — hanya satu perangkat bisa mengirim data dalam satu waktu. Topologi star dengan switch memisahkan collision domain sehingga setiap perangkat bisa mengirim data secara simultan. Ini alasan mengapa topologi star lebih unggul dari bus.
3. **Perkembangan Jaringan:** Dari topologi bus (jaringan coaxial 10BASE2 era 1980-an), star (Ethernet dengan hub/switch 1990-an), hingga mesh nirkabel (WiFi mesh 2010-an). Setiap evolusi menyelesaikan kelemahan topologi sebelumnya.
4. **Network Address Translation (NAT):** Router rumah menggunakan NAT (Network Address Translation) untuk menerjemahkan alamat IP lokal (192.168.x.x) ke alamat IP publik. Ini memungkinkan banyak perangkat di rumah berbagi satu koneksi internet.
