### B. TUJUAN PEMBELAJARAN

#### B.1 Tujuan
1. Menggunakan heading styles untuk membuat daftar isi otomatis pada dokumen.
2. Menambahkan header, footer, page number, dan section break pada dokumen multi-bab.
3. Membuat footnote dan endnote untuk referensi dalam dokumen ilmiah.
4. Melakukan mail merge untuk membuat dokumen massal dari data spreadsheet.
5. Menyusun daftar pustaka otomatis menggunakan fitur References/Citations.

#### B.2 Indikator Keberhasilan
- [ ] Peserta didik membuat dokumen 3 halaman dengan daftar isi otomatis yang bisa di-update.
- [ ] Peserta didik berhasil membuat 3 surat undangan menggunakan mail merge.
- [ ] Peserta didik menambahkan header/footer dan footnote pada dokumen.
- [ ] Peserta didik menyusun daftar pustaka dengan format yang rapi dan konsisten.

#### B.3 Kata Kunci
Heading styles, daftar isi otomatis, mail merge, data source, field, header, footer, section break, footnote, endnote, daftar pustaka, template dokumen

**Bentuk:** Produk — Makalah format lengkap

1. Daftar isi otomatis
2. Header (nama & judul) + footer (nomor halaman)
3. Minimal 3 footnote
4. Daftar pustaka minimal 3 sumber (format APA)
5. Section break antara bab

#### D.4 Rubrik Penilaian
| Kriteria | SB (4) | B (3) | C (2) | PB (1) |

| Header/Footer | Lengkap + section break + footnote | Header + footer | Sebagian | Tidak ada |
| Daftar Pustaka | 3 sumber APA sempurna | 3 sumber, minor error | 2 sumber | Tidak ada |

### H. BAHAN BACAAN UNTUK GURU

1. **Tips:** Simpan file sebelum mail merge. Shortcut: Ctrl+Enter (page break), Alt+Shift+O (TOC).

2. **Error:** Mail merge tidak muncul (Excel belum disave/field salah), daftar isi tidak update, footnote acak, daftar pustaka error.

3. **Word vs Google Docs:** Mail merge native di Word, ekstensi di Docs. Chromebook arahkan ke Docs.
