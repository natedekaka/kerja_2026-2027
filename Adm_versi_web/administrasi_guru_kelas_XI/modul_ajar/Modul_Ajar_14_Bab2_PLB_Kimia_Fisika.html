MODUL AJAR INFORMATIKA KELAS XI

14. PLB — Simulasi Kimia & Fisika dengan Program

Informasi Umum
Mata Pelajaran Informatika
Kelas / Fase XI (Sebelas) / Fase F

Target Peserta Didik Reguler (tidak ada kesulitan belajar khusus)
Model Pembelajaran Tatap muka — Problem Based Learning / Project Based Learning

A. TUJUAN PEMBELAJARAN

Peserta didik mampu mengembangkan program modular sebagai solusi persoalan nyata lintas bidang (Kimia/Fisika).

B. PEMAHAMAN BERMAKNA

Peserta didik mampu mengembangkan program modular sebagai solusi persoalan nyata lintas bidang (Kimia/Fisika).

C. PERTANYAAN PEMANTIK

  1. Bagaimana cara programmer membantu ilmuwan kimia menghitung stoikiometri secara otomatis?
  2. Apa hubungan rumus gerak parabola dengan konsep fungsi dalam pemrograman?
  3. Mengapa simulasi komputer menjadi alat penting dalam penelitian fisika dan kimia modern?

D. KEGIATAN PEMBELAJARAN

Tahap Aktivitas Waktu
Pendahuluan 1) Orientasi, apersepsi, motivasi 15’
2) Pertanyaan pemantik 10’
Inti 1) Penugasan: Setiap kelompok memilih topik — simulasi reaksi kimia (stokiometri, laju reaksi) ATAU simulasi gerak fisika (GLBB, gerak parabola, atau Hukum Newton) (30’)
2) Perancangan: Analisis masalah, rumus yang digunakan, desain fungsi modular — minimal 5 fungsi dengan parameter input yang jelas (45’)
3) Coding: Implementasi program modular — kimia: hitung_mol, stoikiometri_reaksi, laju_reaksi; fisika: hitung_kecepatan_akhir, jarak_tempuh_parabola, gaya_gesek (80’)
4) Pengujian: Testing dengan data percobaan nyata (contoh data dari soal fisika/ kimia), debugging jika ada kesalahan hitung (15’) 170’
Penutup Refleksi, kesimpulan, tugas 30’
