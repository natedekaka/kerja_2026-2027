C.3 Kunci Jawaban Uraian PTS

No. 1 Flowchart Bilangan Prima:
- Start → Input n → Jika n ≤ 1 → Output “Bukan Prima” → Selesai
- Loop i dari 2 sampai n/2 → Jika n % i == 0 → Output “Bukan Prima” → Selesai
- Jika tidak ada yang habis membagi → Output “Prima” → Selesai

No. 2 Langkah Mail Merge:
1. Siapkan data di Excel (daftar nama, alamat, dll)
2. Di Word: Mailings → Start Mail Merge → Letters
3. Pilih Recipients → Use Existing List → pilih file Excel
4. Insert merge field (nama, alamat, dll) di dokumen
5. Preview Results → Finish & Merge

No. 3 Mekanisme Booting:
1. Power on → power supply mengirim sinyal ke motherboard
2. BIOS/UEFI menjalankan POST (Power-On Self-Test): cek HW
3. BIOS mencari bootloader di storage (HDD/SSD)
4. Bootloader memuat sistem operasi ke RAM
5. OS mengambil alih kontrol → tampil desktop/shell
