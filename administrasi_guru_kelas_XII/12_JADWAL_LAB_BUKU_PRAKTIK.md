Kelas XII (11 rombel) bersama XI (12 rombel) dibagi menjadi **2 Grup** — bergantian lab tiap minggu:

```
MINGGU A:                   MINGGU B:
┌─ LAB ─┐  ┌─ KELAS ─┐     ┌─ LAB ─┐  ┌─ KELAS ─┐
│ XII-A │  │ XII-B   │     │ XII-B │  │ XII-A   │
│ XI-A  │  │ XI-B    │     │ XI-B  │  │ XI-A    │
│ X     │  │         │     │ X     │  │         │
└───────┘  └─────────┘     └───────┘  └─────────┘
```

- **Kelas XII-A** (XII.1–XII.5, 5 kelas): Lab di **Minggu A**
- **Kelas XII-B** (XII.6–XII.11, 6 kelas): Lab di **Minggu B**

- **Kelas XI-B** (XI.7–XI.12): Lab di **Minggu B**

> **Ketika tidak lab → pembelajaran teori di kelas masing-masing (5 JP teori).**

## D. ATURAN PRAKTIKUM INFORMATIKA

### D.1 Prosedur Sebelum Praktik
1. Berdoa sebelum memulai kegiatan
2. Cek kondisi perangkat yang akan digunakan (komputer, Arduino, sensor, kabel)
3. Login dengan akun masing-masing
4. Baca LKPD/modul praktik dengan teliti
5. Siapkan alat dan bahan yang diperlukan di meja kerja
6. Pastikan Arduino terhubung ke port USB dengan benar

### D.2 Prosedur Selama Praktik
1. Ikuti langkah kerja sesuai LKPD
2. Catat hasil pengamatan dan temuan selama praktik
3. Jika ada masalah/error, tanya ke guru sebelum meminta bantuan teman
4. Tidak boleh bermain game, media sosial, atau browsing tidak terkait selama praktik
5. Untuk praktik Arduino: rangkai di breadboard dulu sebelum menghubungkan ke listrik
6. Jangan mencabut kabel USB secara paksa — eject terlebih dahulu
7. Kembalikan komponen ke tempat semula jika tidak digunakan

### D.3 Prosedur Setelah Praktik
1. Simpan file project (.ino, .py, .pkt) di folder masing-masing / upload ke Google Classroom
2. Lepaskan komponen Arduino dari breadboard dan rapikan
3. Kembalikan sensor, kabel, dan komponen ke kotak penyimpanan
4. Logout dari akun komputer
5. Matikan komputer dengan prosedur yang benar
6. Rapikan meja dan kursi
7. Guru memastikan semua perangkat mati dan ruangan bersih
