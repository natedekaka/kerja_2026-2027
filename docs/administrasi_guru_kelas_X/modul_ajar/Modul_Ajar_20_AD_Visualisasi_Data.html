B. TUJUAN PEMBELAJARAN

B.1 PEMAHAMAN BERMAKNA (MEANINGFUL)

Data adalah ‘minyak baru’ di era digital. Kemampuan menganalisis data membuka peluang karir dan membantu pengambilan keputusan yang lebih baik.

B.2 PERTANYAAN PEMANTIK (MINDFUL)

  1. Apa yang akan terjadi jika…?
  2. Bagaimana konsep ini terhubung dengan kehidupan sehari-harimu?
  3. Mengapa materi ini penting untuk dipelajari?

B.1 Tujuan Pembelajaran

  1. Memilih jenis grafik yang tepat berdasarkan jenis data dan tujuan visualisasi.
  2. Membuat visualisasi data (bar chart, line chart, pie chart, scatter plot) menggunakan Google Sheets.
  3. Membangun dashboard interaktif menggunakan Google Looker Studio.
  4. Menarik interpretasi dan insight dari visualisasi data yang dibuat.
  5. Menyajikan hasil analisis data dalam bentuk laporan yang komunikatif.

B.2 Indikator Keberhasilan

Indikator Kriteria
Memilih jenis grafik tepat untuk 3 skenario berbeda 3 dari 3 skenario pilihan grafik tepat
Membuat 3 jenis grafik berbeda di Google Sheets 3 grafik jadi, rapi, berlabel, ada judul
Membangun dashboard Looker Studio dengan 2+ grafik Dashboard interaktif, ada filter, data terhubung
Menulis 3 interpretasi dari visualisasi 3 insight logis, berdasarkan data, bukan opini

B.3 Kata Kunci

Visualisasi data, bar chart, line chart, pie chart, scatter plot, dashboard, Looker Studio, data storytelling, insight, interpretasi, data point, sumbu X, sumbu Y, legend, filter interaktif

D. ASESMEN

D.1 Asesmen Diagnostik

  1. Sebutkan jenis grafik yang kalian tahu!
  2. Grafik apa yang cocok untuk menampilkan tren nilai selama 1 semester?
  3. Apa yang dimaksud dengan dashboard?

D.2 Asesmen Formatif

Observasi saat praktik grafik dan dashboard. Ceklist: berapa jenis grafik berhasil dibuat, apakah dashboard terhubung dengan data, apakah ada filter.

D.3 Asesmen Sumatif

  1. Dashboard Looker Studio (produk praktik)
  2. Lembar interpretasi (3 insight dari data)
  3. Tugas Final AD: laporan analisis data + dashboard

D.5 Contoh Soal/Tugas

“Soal: Sebuah perusahaan memiliki data penjualan selama 12 bulan. Mereka ingin melihat: (1) Tren penjualan bulanan, (2) Proporsi penjualan per produk, (3) Perbandingan penjualan antar kota. Jenis grafik apa yang tepat untuk masing-masing? Jelaskan alasannya!”

F. DIFERENSIASI PEMBELAJARAN

  1. Level Dasar (C): Siswa mendapat data siap pakai. Fokus membuat 2 grafik di Sheets. Dashboard menggunakan template. Interpretasi dipandu pertanyaan pemicu.
  2. Level Menengah (B): Menggunakan data polling sendiri. Membuat 3 grafik. Dashboard dari awal dengan panduan minimal. Interpretasi mandiri.
  3. Level Mahir (A): Eksplorasi grafik lanjutan: combo chart, histogram, geo chart. Dashboard dengan calculated fields. Interpretasi mencakup rekomendasi tindakan.

G. REFLEKSI GURU

  2. Apakah Looker Studio terlalu kompleks untuk kelas X? Perlu alat lebih sederhana?
  3. Bagian mana yang paling sulit — menghubungkan data ke Looker Studio atau mendesain dashboard?
  4. Apakah interpretasi siswa sudah berdasarkan data atau masih opini?
  5. Apakah tugas final AD realistis dengan waktu tersisa? Perlu tambahan waktu?

H. BAHAN BACAAN UNTUK GURU

  1. Prinsip Visualisasi Data (Edward Tufte): Konsep data-ink ratio — proporsi tinta untuk data vs elemen dekoratif. Semakin tinggi rasio, semakin baik. Hindari chartjunk (garis grid berlebihan, efek 3D, gradien warna). Lie factor: jangan memanipulasi skala sumbu.
  2. Jenis Grafik dan Penggunaannya: Bar chart untuk perbandingan kategori (batang horizontal untuk label panjang). Line chart untuk data kontinu/waktu (jangan putus sumbu Y jika tidak perlu). Pie chart untuk maksimal 5 kategori (urutkan dari terbesar ke terkecil). Scatter plot untuk melihat korelasi (tambah trendline jika perlu).
  3. Dashboard Design Principles: (1) Tempatkan grafik paling penting di kiri atas (pola baca mata). (2) Gunakan warna konsisten — warna merah untuk perhatian, hijau untuk positif. (3) Tambahkan filter interaktif untuk eksplorasi data. (4) Sertakan teks narasi singkat. (5) Sesuaikan ukuran grafik dengan kepentingannya. Looker Studio mendukung semua fitur ini.
  4. Data Storytelling: Visualisasi data yang efektif menceritakan kisah, bukan sekadar menampilkan angka. Struktur data storytelling: (1) Konteks — apa yang sedang terjadi? (2) Konflik — apa tantangan/masalahnya? (3) Resolusi — apa yang data katakan? (4) Call to action — apa yang harus dilakukan? Contoh: “Kelas X suka olahraga (konteks), tapi fasilitas terbatas (konflik), data menunjukkan 60% siswa ingin futsal (resolusi), sekolah perlu tambah lapangan futsal (aksi).”
