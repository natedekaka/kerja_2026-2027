B. TUJUAN PEMBELAJARAN

B.1 PEMAHAMAN BERMAKNA (MEANINGFUL)

Kemampuan mengolah kata, angka, dan presentasi secara terintegrasi adalah skill esensial di dunia perkantoran dan akademik modern.

B.2 PERTANYAAN PEMANTIK (MINDFUL)

  1. Apa yang akan terjadi jika…?
  2. Bagaimana konsep ini terhubung dengan kehidupan sehari-harimu?
  3. Mengapa materi ini penting untuk dipelajari?

B.1 Tujuan

Melalui eksplorasi dan praktik langsung, peserta didik mampu:
1. Menggunakan formula dasar (+, -, *, /) dan fungsi bawaan (SUM, AVERAGE, COUNT, MAX, MIN)
2. Menggunakan fungsi lookup (VLOOKUP/XLOOKUP) dan logika (IF)
3. Membuat grafik/chart dari data
4. Menyusun data dalam bentuk tabel yang terstruktur

B.2 Indikator Keberhasilan

  • ✅ Mengolah data menggunakan minimal 5 fungsi (SUM, AVERAGE, VLOOKUP, IF, COUNTIF) dengan benar
  • ✅ Membuat minimal 2 jenis grafik yang sesuai dengan data
  • ✅ Data tersusun rapi dalam format tabel yang profesional

B.3 Kata Kunci

Spreadsheet, formula, fungsi, SUM, AVERAGE, VLOOKUP, IF, COUNTIF, grafik, pivot table

E. LEMBAR KERJA PESERTA DIDIK (LKPD)

LKPD-03: SPREADSHEET — LAPORAN PENJUALAN

Nama: __ Kelas: __

Bagian A: Buat Data Berikut

| Kode Produk | Nama Produk | Harga Satuan | Jumlah Terjual | Total |
|—|—|—|—|—|—|
| BRG-001 | Buku Tulis | 5.000 | 150 | |
| BRG-002 | Pensil | 2.000 | 200 | |
| BRG-003 | Penghapus | 3.000 | 80 | |
| BRG-004 | Penggaris | 4.000 | 60 | |
| BRG-005 | Spidol | 8.000 | 120 | |

Bagian B: Gunakan Fungsi

No Perintah Fungsi Hasil
1 Hitung Total per barus = D2 * E2
2 Hitung Total Keseluruhan =SUM(F2:F6)
3 Hitung Rata-rata Penjualan =AVERAGE(E2:E6)
4 Barang terlaris =MAX(E2:E6)
5 Barang paling sedikit =MIN(E2:E6)

Bagian C: Buat Grafik

Buat 2 jenis grafik dari data di atas:
1. Grafik Batang — perbandingan jumlah terjual per produk
2. Grafik Pie — kontribusi penjualan per produk

H. BAHAN BACAAN GURU

  • Tips: Ajarkan IF dengan analogi: “Jika kondisi terpenuhi → lakukan A, jika tidak → lakukan B”
  • VLOOKUP: Analogikan seperti “kamus” — cari kata (kode) dapatkan artinya (nama produk)
  • Alternatif: Jika Excel tidak tersedia, Google Sheets adalah alternatif gratis dengan fitur setara
  • Perbedaan: @ (Google Sheets) vs = (Excel) untuk fungsi array — sesuaikan dengan platform yang digunakan
