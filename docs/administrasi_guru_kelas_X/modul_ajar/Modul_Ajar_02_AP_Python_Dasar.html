B. TUJUAN PEMBELAJARAN

B.1 Tujuan

Melalui kegiatan demonstrasi dan praktik langsung, peserta didik mampu:
1. Menjelaskan perbedaan tipe data (integer, float, string, boolean)
2. Mendeklarasikan variabel dengan nama yang tepat sesuai konvensi Python
3. Menggunakan fungsi input() untuk menerima masukan dan print() untuk menampilkan output
4. Menulis program sederhana yang menggabungkan variabel, tipe data, dan I/O

B.2 Indikator Keberhasilan

  • ✅ Menulis program Python dengan deklarasi variabel minimal 3 tipe data berbeda
  • ✅ Program dapat menerima input dari pengguna dan menampilkan output yang sesuai
  • ✅ Program berjalan tanpa error sintaksis

B.3 Kata Kunci

Python, variabel, tipe data, integer, float, string, boolean, input(), print(), casting

Kriteria SB (4) B (3) C (2) PB (1)

Tipe Data Menggunakan 4 tipe data (int, float, str, bool) 3 tipe data 2 tipe data 1 tipe data

D.5 Contoh Program Target

# Program Profil Diri
nama = input("Masukkan nama kamu: ")
umur = int(input("Masukkan umur kamu: "))
tinggi = float(input("Masukkan tinggi badan (cm): "))
kelas = input("Masukkan kelas: ")

print("\n========== PROFIL DIRI ==========")
print(f"Halo, namaku {nama}.")
print(f"Aku berumur {umur} tahun.")
print(f"Tinggiku {tinggi} cm.")
print(f"Aku duduk di kelas {kelas}.")

Bagian C: Tantangan (Pilih sesuai kemampuanmu)

☀️ Mudah — Program Sapa
Buat program yang meminta nama dan menyapa: “Halo [nama]! Selamat belajar Python!”

⛅ Sedang — Konversi Suhu
Buat program yang menginput Celcius lalu mengoutput Fahrenheit. Rumus: F = (C × 9/5) + 32

🌤️ Sulit — Luas Lingkaran
Buat program yang menginput jari-jari lingkaran lalu mengoutput luas. Rumus: L = π × r² (π = 3.14)

H. BAHAN BACAAN UNTUK GURU

  • Python untuk Pemula: Gunakan analogi “variabel = kotak penyimpanan”, “tipe data = jenis barang yang disimpan”
  • Error Umum: NameError (salah nama variabel), TypeError (operasi antar tipe berbeda), ValueError (input tidak sesuai)
  • Tools Alternatif: Jika Python IDLE tidak tersedia, gunakan Replit.com (akses web, gratis) atau Google Colab
  • Strategi Debugging: Ajarkan siswa membaca error message — ini keterampilan paling penting dalam coding!
