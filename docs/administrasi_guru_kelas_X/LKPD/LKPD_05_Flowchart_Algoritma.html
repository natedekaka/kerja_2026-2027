LKPD - Flowchart Algoritma Kehidupan Sehari-hari

Mata Pelajaran: Informatika
Kelas/Semester: X / Ganjil
Materi Pokok: Bab 7 – Algoritma dan Pemrograman (Flowchart)
Alokasi Waktu: 2 JP (1 JP = 45 menit)

A. Tujuan Pembelajaran

  1. Peserta didik mampu menjelaskan pengertian algoritma dan flowchart.
  2. Peserta didik mampu mengidentifikasi simbol-simbol dalam flowchart.
  3. Peserta didik mampu membuat flowchart untuk algoritma kehidupan sehari-hari.
  4. Peserta didik mampu membuat flowchart untuk algoritma sederhana (menghitung, menentukan nilai).

B. Alat dan Bahan

  1. Alat tulis (kertas HVS/polos, pensil, penghapus, penggaris).
  2. Komputer/laptop (opsional, untuk menggambar flowchart digital menggunakan draw.io atau tools lain).
  3. Buku paket Informatika Kelas X.

C. Langkah Kerja

Tahap 1: Mengenal Simbol Flowchart

  1. Pelajari dan catat simbol-simbol flowchart berikut:
Simbol Nama Fungsi
Oval / Terminator Mulai / Selesai
Persegi panjang Proses (perhitungan, assignment)
Jajar genjang Input / Output
Belah ketupat Decision / Percabangan (Ya/Tidak)
Lingkaran kecil Connector (penghubung)
Panah Alur / Flow
  1. Gambarkan masing-masing simbol beserta fungsinya di buku catatan.

Tahap 2: Flowchart Aktivitas Sehari-hari (Individu)

  1. Pilih satu aktivitas sehari-hari dari daftar berikut:
    - Cara membuat mie instan
    - Prosedur menggosok gigi
    - Langkah menyalakan komputer dan login
    - Persiapan berangkat sekolah
  2. Tuliskan algoritma dalam bentuk deskripsi (narasi) terlebih dahulu.
  3. Ubah algoritma tersebut ke dalam bentuk flowchart menggunakan simbol yang benar.
  4. Flowchart minimal terdiri dari: Mulai, Input/Output, Proses, Decision (minimal 1), Selesai.

Tahap 3: Flowchart Algoritma Sederhana (Berpasangan)

Buat flowchart untuk algoritma berikut:

Soal A: Menentukan Bilangan Ganjil/Genap

  1. Algoritma:
    - Mulai
    - Input sebuah bilangan bulat
    - Jika bilangan dibagi 2 sisa 0, maka output “Genap”
    - Jika tidak, output “Ganjil”
    - Selesai
  2. Gambarkan flowchart-nya.

Soal B: Menghitung Rata-rata 3 Bilangan

  1. Algoritma:
    - Mulai
    - Input bilangan A, B, C
    - Hitung rata-rata = (A + B + C) / 3
    - Output rata-rata
    - Selesai
  2. Gambarkan flowchart-nya.

Soal C: Menentukan Kelulusan

  1. Algoritma:
    - Mulai
    - Input nilai Ujian
    - Jika nilai >= 75, output “Lulus”
    - Jika nilai < 75, output “Tidak Lulus”
    - Selesai
  2. Gambarkan flowchart-nya.

Tahap 4: Presentasi dan Review (Kelompok)

  1. Tukarkan flowchart dengan kelompok lain.
  2. Periksa apakah ada kesalahan alur atau simbol yang kurang tepat.
  3. Beri masukan pada hasil kerja kelompok lain.

D. Tabel Hasil

No Jenis Flowchart Simbol yang Digunakan Jumlah Decision Apakah Alur Logis? (Ya/Tidak)
1 Aktivitas Sehari-hari: [nama aktivitas]
2 Ganjil/Genap
3 Rata-rata 3 Bilangan
4 Menentukan Kelulusan

E. Diskusi dan Analisis

  1. Apa perbedaan antara algoritma yang ditulis secara narasi dengan flowchart?
  2. Mengapa dalam flowchart kita perlu menggunakan decision (percabangan)? Beri contoh kasus yang membutuhkan decision!
  3. Apa yang terjadi jika dalam flowchart Menentukan Kelulusan tidak ada simbol decision?
  4. Dalam flowchart Rata-rata 3 Bilangan, apakah ada langkah yang bisa dihilangkan? Mengapa?
  5. Menurutmu, apakah semua aktivitas sehari-hari bisa dibuat flowchart? Berikan 1 contoh aktivitas yang sulit dibuat flowchart dan jelaskan alasannya!

F. Kesimpulan

Tuliskan kesimpulan tentang pentingnya algoritma dan flowchart dalam menyelesaikan masalah!
