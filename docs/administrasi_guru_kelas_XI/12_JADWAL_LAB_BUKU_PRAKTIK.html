Sistem Rotasi 2 Mingguan

Kelas XI (12 rombel) dan XII (11 rombel) dibagi menjadi 2 Grup — bergantian lab tiap minggu:

MINGGU A:                   MINGGU B:
┌─ LAB ─┐  ┌─ KELAS ─┐     ┌─ LAB ─┐  ┌─ KELAS ─┐
│ XI-A  │  │ XI-B    │     │ XI-B  │  │ XI-A    │
│ XII-A │  │ XII-B   │     │ XII-B │  │ XII-A   │
│ X     │  │         │     │ X     │  │         │
└───────┘  └─────────┘     └───────┘  └─────────┘

  • Kelas XI-B (XI.7–XI.12): Lab di Minggu B
  • Kelas XII-A (XII.1–XII.5): Lab di Minggu A
  • Kelas XII-B (XII.6–XII.11): Lab di Minggu B
  • Kelas X (11 rombel, 2 JP): Lab setiap minggu (Kamis–Jumat)

Ketika tidak lab → pembelajaran teori di kelas masing-masing (5 JP teori).
