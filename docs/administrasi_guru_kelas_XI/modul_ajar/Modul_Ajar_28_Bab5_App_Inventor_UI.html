MODUL AJAR INFORMATIKA KELAS XI

28. App Inventor — UI & Event Handling

Informasi Umum
Mata Pelajaran Informatika
Kelas / Fase XI (Sebelas) / Fase F
Bab Bab 5 — Aplikasi Mobile dengan Library AI
Alokasi Waktu 5 JP × 45 menit = 225 menit
Pertemuan ke- 28
Tujuan Pembelajaran TP.5.2 (bagian 1)
Integrasi 8 Dimensi Kreativitas, Kemandirian
Sarana & Prasarana Komputer/lab, proyektor, koneksi internet, LKPD
Target Peserta Didik Reguler (tidak ada kesulitan belajar khusus)
Model Pembelajaran Tatap muka — Problem Based Learning / Project Based Learning

A. TUJUAN PEMBELAJARAN

Peserta didik mampu mengembangkan aplikasi mobile berbasis blok menggunakan App Inventor dengan UI dan event handling.

B. PEMAHAMAN BERMAKNA

Peserta didik mampu mengembangkan aplikasi mobile berbasis blok menggunakan App Inventor dengan UI dan event handling.

C. PERTANYAAN PEMANTIK

  1. Bagaimana cara membuat aplikasi ponsel tanpa menulis kode pemrograman yang rumit?
  2. Apa yang terjadi saat pengguna menekan tombol pada layar ponsel?
  3. Mengapa tampilan antarmuka aplikasi perlu dirancang dengan baik?

D. KEGIATAN PEMBELAJARAN

Tahap Aktivitas Waktu
Pendahuluan 1) Orientasi, apersepsi, motivasi 15’
2) Pertanyaan pemantik 10’
Inti 1) Pengenalan: Antarmuka App Inventor — designer, blocks editor, komponen (30’)
2) UI Design: Membuat layout — button, label, textbox, listview, image (45’)
3) Event Handling: OnClick, OnLongClick, timer, gesture — kapan menggunakan masing-masing (45’)
4) Praktik: Membuat aplikasi “Kalkulator Sederhana” dengan UI responsif + event handler (50’) 170’
Penutup Refleksi, kesimpulan, tugas 30’
