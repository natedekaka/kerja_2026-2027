  4. Menilai kemampuan berpikir kritis peserta didik terhadap isu-isu dampak sosial Informatika.

    a. A + C (total nilai 70, berat 11 — melebihi kapasitas)
    b. A + B + D (total nilai 65, berat 12 — melebihi kapasitas)
    c. B + C (total nilai 60, berat 10)
    d. A + D (total nilai 45, berat 8)
    e. C + D (total nilai 55, berat 9)

    Jawaban: C + D = 40+15=55, berat 9 ✓
    Atau B + C = 20+40=60, berat 10 ✓

C.3 Praktik Coding (1 Soal)

Petunjuk: Kerjakan di komputer yang telah disediakan! Simpan file dengan format: Nama_Kelas_NoAbsen_PTS.py

Buatlah sebuah program Python untuk Sistem Rekomendasi Menu Makanan Sehat dengan spesifikasi berikut:

  1. Program menyediakan daftar menu makanan dengan data: nama, kalori, protein, lemak, karbohidrat, dan harga.
  2. Input: pengguna memasukkan target kalori harian (misal 2000 kal).
  3. Program menentukan kombinasi menu yang memaksimalkan jumlah item makanan dengan total kalori tidak melebihi target (gunakan pendekatan Greedy atau DP — pilih yang paling tepat dan jelaskan alasannya dalam komentar).
  4. Output: daftar menu yang dipilih, total kalori, total biaya, dan total protein.
  5. Program harus dilengkapi dengan minimal:
    - 1 fungsi rekursif atau DP
    - Penggunaan array/list dan string
    - Input/output yang interaktif
    - Komentar yang menjelaskan logika setiap bagian
