A. TUJUAN PEMBELAJARAN

B. PEMAHAMAN BERMAKNA

Peserta didik mampu menggunakan struktur data array dan string untuk manipulasi data lanjutan.

C. PERTANYAAN PEMANTIK

  1. Mengapa kita perlu mempelajari struktur data seperti array dan string secara lebih mendalam?
  2. Apa perbedaan utama antara array satu dimensi dan dua dimensi? Berikan contoh masing-masing!
  3. Bagaimana komputer menyimpan dan memproses teks (string) di dalam memorinya?

D. KEGIATAN PEMBELAJARAN

Tahap Aktivitas Waktu
Pendahuluan 1) Orientasi, apersepsi, motivasi 15’
2) Pertanyaan pemantik 10’
Inti 1) Review: Array 1D, 2D, operasi dasar — indexing, slicing, iterasi, array dalam Python (list) (30’)
2) Sorting: Implementasi merge sort (divide & conquer) dan quick sort (partitioning) pada array bilangan (60’)
3) Searching: Binary search pada array terurut, interpolation search untuk distribusi data merata (45’)
4) String: Operasi string lanjutan — slicing, formatting f-string, metode built-in (.split, .join, .replace) dan pengenalan regex dasar (35’) 170’
Penutup Refleksi, kesimpulan, tugas 30’
