A. TUJUAN PEMBELAJARAN

  1. Mengukur pencapaian kompetensi peserta didik pada materi Bab 4–6 (Semester Genap).
  2. Mengevaluasi penguasaan konsep jaringan komputer, keamanan siber, dan konfigurasi jaringan.
  3. Menilai kemampuan pengembangan aplikasi mobile berbasis AI dan integrasi library AI.
  4. Mengukur kompetensi analisis data — dari pengolahan hingga visualisasi dan penarikan kesimpulan.
  5. Menilai kemampuan peserta didik dalam menghasilkan produk nyata (proyek aplikasi/analisis data).

  2. (Bab 4) Sebuah startup memiliki 50 karyawan dengan data sensitif pelanggan. Mereka menyewa ruang kantor dengan jaringan WiFi publik di gedung perkantoran.

    b. Evaluasi risiko dari setiap ancaman!

  3. (Bab 5) Anda diminta merancang aplikasi mobile bernama “SiParkir” — aplikasi pendeteksi ketersediaan parkir menggunakan kamera ponsel.

  4. (Bab 6) Diberikan dataset fiktif berikut:

  5. (Bab 6) Sebuah perusahaan e-commerce ingin menganalisis data transaksi untuk meningkatkan penjualan.
    a. Rancang kerangka proyek analisis data: dari pertanyaan bisnis, pengumpulan data, pengolahan, analisis, hingga rekomendasi!

C.3 Uji Kinerja / Proyek (1 Soal)

Petunjuk: Pilih SALAH SATU dari tiga opsi berikut! Kerjakan di komputer yang disediakan!

Opsi A — Jaringan (Konfigurasi Cisco Packet Tracer)
Buatlah desain dan konfigurasi jaringan untuk SMA Negeri 6 Cimahi dengan ketentuan:
- 3 gedung: A (20 komputer), B (15 komputer), C (10 komputer)
- Masing-masing gedung dalam VLAN terpisah
- 1 server pusat di gedung A
- Koneksi internet melalui router ke ISP
- Konfigurasi: IP addressing, routing antar VLAN, DHCP server, ACL untuk membatasi akses server
- Uji konektivitas (ping) antar perangkat
- Simpan file sebagai: Nama_Kelas_NoAbsen_PAT.pkt

Opsi B — Aplikasi Mobile (App Inventor)
Buatlah aplikasi mobile “Pengecek Kualitas Udara” dengan fitur:
- Input: lokasi (text) dan angka polusi (PM2.5, PM10)
- Menggunakan komponen: Label, Button, TextBox, ListView, Notifier
- Fitur AI: klasifikasi kualitas udara (baik/sedang/tidak sehat/berbahaya) menggunakan logika if-else (simulasi AI)
- Simpan data pengukuran ke TinyDB
- Tampilkan riwayat pengukuran
- Ekspor file .aia sebagai: Nama_Kelas_NoAbsen_PAT.aia

Opsi C — Analisis Data (Python/Spreadsheet)
Buatlah laporan analisis data dengan tema “Analisis Pola Penggunaan Internet Siswa”:
- Buat dataset minimal 20 baris (tiruan) dengan kolom: jam_penggunaan_per_hari, media_sosial_favorit, tujuan_utama, nilai_rata_rata
- Lakukan: data cleaning, statistik deskriptif, visualisasi (minimal 3 grafik)
- Analisis: apakah ada korelasi antara jam penggunaan internet dan nilai rata-rata?
- Simpan laporan sebagai: Nama_Kelas_NoAbsen_PAT.pdf/docx
