A. CAPAIAN PEMBELAJARAN (CP)

Elemen CP:

  • AL: Algoritma dan Pemrograman

Teks CP:

  • Pada akhir fase F, peserta didik mampu menerapkan strategi algoritmik standar untuk mengembangkan program komputer yang terstruktur dalam bahasa pemrograman prosedural (C/C++) untuk Arduino, menggunakan pustaka standar, serta mampu menguji dan menyempurnakan program.

B. TUJUAN PEMBELAJARAN (TP)

TP pada Bab Ini:

  • 3.1. Peserta didik mampu menjelaskan dan menerapkan manfaat berpikir komputasional dalam kehidupan sehari-hari
  • 3.2. Peserta didik mampu menjelaskan dan menerapkan dasar pemrograman bahasa c untuk arduino
  • 3.3. Peserta didik mampu menjelaskan dan menerapkan struktur dasar program c (variabel, tipe data, operator)
  • 3.4. Peserta didik mampu menjelaskan dan menerapkan struktur kontrol: percabangan dan perulangan
  • 3.5. Peserta didik mampu menjelaskan dan menerapkan array dan manipulasi data
  • 3.6. Peserta didik mampu menjelaskan dan menerapkan fungsi dan library arduino
  • 3.7. Peserta didik mampu menjelaskan dan menerapkan proyek pennrograman: aplikasi kontrol otomatis

TP Khusus Pertemuan Ini:

3.6. Peserta didik mampu memahami dan menerapkan konsep fungsi dan library arduino

C. INDIKATOR KETERCAPAIAN TUJUAN PEMBELAJARAN

  • Peserta didik mampu menjelaskan konsep fungsi dan library arduino dengan benar
  • Peserta didik mampu mengidentifikasi komponen/pilar utama dari fungsi dan library arduino
  • Peserta didik mampu menerapkan konsep fungsi dan library arduino dalam studi kasus

J. KEGIATAN PEMBELAJARAN (DEEP LEARNING: MINDFUL → MINING → JOYFUL)

Tahap 1: MINDFULL (Pemanasan Berkesadaran) — 20 menit

  1. Guru membuka dengan salam, doa bersama (7 KAIH: Beribadah), presensi
  2. Apersepsi: mengaitkan materi dengan pengalaman peserta didik
  3. Pertanyaan pemantik untuk membangkitkan rasa ingin tahu
  4. Guru menyampaikan tujuan pembelajaran dan skenario kegiatan

Tahap 2: MINING FULL (Eksplorasi Mendalam) — 175 menit

Model Discovery Learning + Cooperative Learning:
1. Stimulation (20 menit): Peserta didik mengamati tayangan/gambar/artikel terkait materi
2. Problem Statement (25 menit): Guru memberikan pertanyaan-pertanyaan kunci
3. Data Collection (50 menit): Peserta didik mengumpulkan informasi dari buku dan sumber digital
4. Data Processing (40 menit): Diskusi kelompok untuk mengolah dan menganalisis informasi
5. Verification (20 menit): Verifikasi hasil diskusi dengan referensi dan bimbingan guru
6. Generalization (20 menit): Menarik kesimpulan bersama

Tahap 3: JOYFULL (Penutup Kreatif & Reflektif) — 30 menit

  1. Game kuis singkat / teka-teki silang konsep
  2. Guru bersama peserta didik menyimpulkan materi secara interaktif
  3. Evaluasi formatif (kuis/pertanyaan lisan)
  4. Tugas mandiri untuk pertemuan berikutnya
  5. Refleksi Deep Learning: “Apa yang paling bermakna hari ini?” + 7 KAIH: “Kebiasaan baik apa yang dipraktikkan?”
  6. Doa bersama dan penutup

Pengayaan

M. GLOSARIUM

  • Berpikir Komputasional: metode pemecahan masalah dengan menerapkan konsep ilmu komputer
  • Variabel: tempat penyimpanan data dalam program
  • Array: struktur data yang menyimpan kumpulan elemen dengan tipe yang sama
  • Fungsi: blok kode yang menjalankan tugas tertentu dan dapat dipanggil berulang
  • Library: kumpulan fungsi siap pakai dalam pemrograman
